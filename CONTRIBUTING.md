# Contributing to StudyMate

Thanks for helping improve StudyMate.

## Principles

- Protect learner privacy.
- Never commit credentials or private study material.
- Keep source provenance visible.
- Prefer grounded answers over unsupported generation.
- Keep retrieval independent from the AI provider where practical.
- Preserve deterministic document rendering.
- Make changes understandable and reviewable.

## Development

Create a branch for your change and keep commits focused.

Before submitting a pull request:

1. Confirm Python compiles.
2. Confirm frontend JavaScript parses.
3. Check that no secrets or private data are included.
4. Explain what changed and why.
5. Include testing notes.

StudyMate is currently an early-stage project, so architecture may evolve.
